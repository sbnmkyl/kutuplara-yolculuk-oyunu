# Kutuplara Yolculuk

3D, animasyonlu, sertifikalı kutup bilim diplomasisi oyunu.

## İçerik

- 20 soruluk test eksiksiz korunmuştur.
- Karakter, arka plan, kutup atmosferi ve animasyonlar oyunun içine hazır yerleştirilmiştir.
- Klavye, WASD ve dokunmatik yön düğmeleri desteklenir.
- Oyun bitince kişiye özel Kutup Elçisi sertifikası PNG olarak indirilebilir.

## Çalıştırma

GitHub Pages için bu klasörü bir depoya yükleyin ve `index.html` dosyasını ana sayfa olarak bırakın.

Yerelde test etmek için klasör içinde basit bir sunucu açabilirsiniz:

```bash
python -m http.server 8000
```

Sonra tarayıcıda şu adresi açın:

```text
http://localhost:8000
```

Not: 3D model dosyaları nedeniyle oyunu doğrudan `file://` ile açmak bazı tarayıcılarda model yükleme kısıtına takılabilir. GitHub Pages veya yerel sunucu ile çalıştırmak en sağlıklı yoldur.
